# rodriguesmath.github.io

Portfólio técnico pessoal de **Rodrigues Matheus** — Engenharia de Computação (IFPB), Sistemas Embarcados *Bare-Metal* (STM32), Robótica (Laboratório Hórus), Interagi Tecnologia e Sistemas Multi-Agentes.

## Arquitetura & Princípios
- **Swiss Grid Typography:** Layout estruturado em grade de 12 colunas (`IBM Plex Sans` + `IBM Plex Mono`), alto contraste e zero dependências pesadas.
- **Acessibilidade:** HTML5 semântico, *skip-link*, estados `focus-visible`, `aria-live` para filtros/ações e suporte a `prefers-reduced-motion` e tema claro/escuro (`prefers-color-scheme`).
- **Deploy:** Hospedado via **GitHub Pages** diretamente da branch `main`.
