# rodriguesmath.github.io

Site pessoal de **Rodrigues Matheus** — Engenharia de Computação (IFPB), Sistemas Embarcados *Bare-Metal* (STM32/ESP32), Robótica (Laboratório Hórus) e Sistemas Multi-Agentes.

## Design & Engenharia
- **Minimalismo Editorial:** Coluna única de leitura (`650px`), tipografia `Inter` + `Newsreader` + `JetBrains Mono` e ausência total de ruído visual ou templates genéricos.
- **Micro-interações táteis:** Efeito de foco por atenuação de irmãos na lista de projetos, alternância suave de tema claro/escuro e suporte a `prefers-reduced-motion`.
- **Acessibilidade (Vercel Web Interface Guidelines):** HTML5 semântico, *skip-link*, `:focus-visible`, `aria-pressed`, `text-wrap: balance/pretty` e `tabular-nums`.
